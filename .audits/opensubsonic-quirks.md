# Sonarly v2 — OpenSubsonic adapter quirks checklist (P6.5–P9b)

> Historical transition-era artifact (2026-09): documents the TypeScript→Go rewrite and cutover. Version names inside refer to the pre- and post-rewrite codebases; preserved as project history.

Archaeology of every behavioral quirk in v1's OpenSubsonic adapter
(`packages/server/src/features/opensubsonic/` + its dependencies), each with
evidence and the v2 decision. This document is the lookup table the P9
phases implemented against; **every quirk row is now done — 62/62** (P9b
completed the set — see the deviation logs at the end; the phase briefs'
"61" was an off-by-one against this 62-row table). Implement against the
decisions here, not by re-reading v1.

Evidence paths are relative to `packages/server/src/` in the v1 checkout.
Decisions are one of **preserve** (wire-compatible copy), **fix** (deliberate
behavior change, rationale given), **defer** (decide during P9).

Version under which quirks were mined: v1 @ main with the getAlbumInfo fix
(commit `ee28138`) and healthz.

## XML mapping reference (v2 `encoding/xml` conventions)

Canonical payload shape (JSON) is converted for XML exactly as v1's `toCompact`:

- scalar field → XML attribute: Go tag `xml:"name,attr"` (+ `omitempty` where v1 omits null/undefined).
- a field named `Value` carrying text → `xml:",chardata"`, rendered as element text (`<genre songCount="3">Rock</genre>`).
- nested struct → child element; slice of structs → repeated child elements (`<artists .../>` per entry); slice of strings → repeated text elements (`<isrcs>X1</isrcs>`).
- empty slice → element omitted (matches xml-js); JSON keeps `[]` when the slice is non-nil.
- envelope root element: `xml.Name` tagged `subsonic-response`.

Known cosmetic deltas (parse-identical, accepted): Go emits `<x></x>` where xml-js emitted `<x/>`; Go escapes `'` in attribute values as `&#39;`; Go puts the XML declaration on `MarshalIndent` output only if asked — v1/xml-js emits **no declaration**, so v2 renders without one.
